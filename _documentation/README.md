# Documentation interne JBC

Notes techniques et guides internes pour la gestion du site et de la pétition.
Ces fichiers ne sont pas servis par le site (Jekyll ignore les dossiers commençant par `_`).

## Fichiers
- `APPS-SCRIPT-URL.md` — URL et configuration du Google Apps Script
- `GUIDE-CORRECTIFS-PETITION.md` — Notes sur les correctifs apportés à la pétition
- `GUIDE-WEBHOOKS-DEMAIN.md` — Plan de connexion des webhooks Netlify
- `PETITION-SETUP.md` — Configuration initiale de la pétition

## Conseil
Ajoutez vos nouvelles notes dans ce dossier. Format Markdown (.md) recommandé.
