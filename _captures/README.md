# Captures d'écran

Dossier dédié aux **captures d'écran que vous prenez pour communiquer avec les IA** (Claude, ChatGPT, Perplexity, etc.).

## Comment l'utiliser
1. Sur Mac, faites une capture avec `Cmd + Shift + 4` (zone) ou `Cmd + Shift + 3` (écran complet)
2. Glissez le fichier ici dans ce dossier
3. Nommez-le clairement, exemple :
   - `2026-04-27-erreur-formulaire-petition.png`
   - `2026-04-28-message-netlify-billing.png`
   - `2026-04-28-screenshot-page-test.png`
4. Quand vous discutez avec l'IA, glissez la capture dans la conversation

## Conseil de nommage
Format recommandé : `AAAA-MM-JJ-sujet-court.png`

Cela vous permettra de retrouver facilement vos captures par date.

## Note
Les PNG/JPG ne sont pas gitignorés par défaut. Si vous voulez que vos captures restent privées (pas sur GitHub), dites-le-moi et j'ajoute une règle.
