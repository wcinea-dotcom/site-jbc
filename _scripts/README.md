# Scripts JBC

Scripts actifs utilisés par le site JBC.

## Google Apps Script
- `google-apps-script-V6.gs` — **Version active** (à coller dans script.google.com)
  - Gère la collection des signatures de la pétition
  - Envoie les emails de confirmation
  - Lock service pour éviter les doublons

Les versions précédentes (V2 à V5) sont dans `_archives/` au cas où.
